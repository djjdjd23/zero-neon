# 零点霓虹 · Zero Neon

横屏像素 · 白天经营，夜里守街。

**在线游玩**：https://djjdjd23.github.io/zero-neon/

手机浏览器打开即玩，**请横屏**。

---

## 玩法

- **◀ ▶** 移动 · **E** 交互
- 走到**五金店**下单 → 走到空位按 **E** 放置 → 施工队自动来建
- 商店会产金币掉在地上，**走过去捡**（钱要自己捡，别指望它自己进钱包）
- 库存卖光要走到店前按 **E** 补货
- 夜里敌人来砸店，**你打不了人**，只能跑动调度
- **唯一失败条件：威望归零**

## 时间

| 阶段 | 时长 | 倍速 |
|---|---|---|
| 白天 | 200 秒 | 1× / 2× / 4× |
| 黄昏 | 45 秒 | 1× / 2× / 4× / 跳过 |
| 夜晚 | 150 秒 | **锁定 1×** |

夜晚锁 1× 是设计决定：那 150 秒必须真的在跑，防守才不是看数字。

## 已实现（MVP v0.1）

- 横屏 320×180 像素渲染，整数放大，全程序化生成（零图片素材）
- 昼夜循环 + 加速按钮 + 黄昏跳过 + 跨夜自动归 1×
- 家（金库/招募/升级/电力）、五金店、24 个可建空位
- 4 种商店：便利店 / 奶茶店 / 小饭馆 / 当铺
- 3 种防御：路障 / 地刺 / 炮塔
- 2 种敌人：小偷 / 砸店党
- 2 种保安：近战 / 远程（机器人需家 Lv6）
- 掉落物 + 当铺变现
- 电力每日固定，超载自动断电
- 家被破坏 → 降 1 级 / 金库 -40% / 当晚结束 / 次日 260 秒
- 特殊 NPC：老周（第 4 天出现 → 建 3 座防御 → 入队）
- 故事第一幕

## 本地运行

直接用浏览器打开 `index.html`，无需构建、无需服务器。

调试参数：

- `?demo` — 直接进入已开工的街景
- `?demo&night` — 夜晚战斗场景
- `?demo&menu` — 打开建造菜单
