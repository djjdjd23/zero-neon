# 零点霓虹 · Zero Neon

横屏像素 · 白天经营，夜里守街。

**在线游玩**：https://djjdjd23.github.io/zero-neon/

手机浏览器打开即玩，**请横屏**。

## 玩法

- 打开先到**开场页** → 选一个**存档槽** → 进入游戏
- **◀ ▶** 移动 · **E** 交互
- 走到**五金店**下单 → 走到空位按 **E** 放置 → 施工队自动来建
- 商店赚的钱记在**店头**（屋顶有金额牌），**走近就自动收进钱包**
- 保安会和敌人**正面互殴**：敌人贴到保安就停下对打，不再绕过去砸店
- 走进店里招**店员**（一个店员占一个二层窗口，收入 +35%）
- 库存卖光要走到店前按 **E** 补货
- 夜里敌人来砸店，**你打不了人**，只能跑动调度
- **黄昏**会给出今晚第一波的情报（方向 / 数量 / 种类），并弹出**布防**面板
- 右上角 **II** 按钮暂停（再点继续）；缺货的店屋顶会亮**红色感叹号**
- 顶部横栏的 **「招募 · …」** 会轮播下一位特殊 NPC 的**招募条件与进度**，点开可看全部八位
- 右上 **「街史」** 是剧情档案（五幕 + 四个结局），**不看也能照常玩**
- 点击面板外的任意位置即可关闭面板
- **唯一失败条件：威望归零**

## 声音

### 背景音乐

真实录音的 **Retro Synthwave Loops**（Tomasz Kucza / Magnesus，CC BY 4.0），5 段无缝循环，按场景切换：

| 场景 | 曲目 | 文件 |
|---|---|---|
| 开场页 | shadow_operations | `audio/shadow_operations-loop1.ogg` |
| 白天 | going_undercover | `audio/going_undercover-loop1.ogg` |
| 黄昏 | deadly_contracts | `audio/deadly_contracts-loop1.ogg` |
| 夜晚 | hostile_territory | `audio/hostile_territory-loop1.ogg` |

用 `fetch + decodeAudioData` 加载，`AudioBufferSourceNode` 循环播放，切场景有 0.5 秒淡出 / 1.4 秒淡入。

### 音效

界面与战斗音效使用 **Chiptune SFX Pack**（CC0）的采样：点击、收钱、受击/命中、失败、升级、结算、拾取。其余（警报、砸店、中枢门等）由 Web Audio 实时合成。

音频**全部加载失败时会自动回退到纯合成**（`SFX` 映射），所以 `file://` 双击打开也能有声音，只是没有音乐文件。

### 控制

- 开场页「音效：开/关」一键切换（同时管 BGM 和音效），偏好存本地
- 手机切后台自动静音、回前台恢复
- 浏览器要求**用户手势**后才能出声，第一次点屏幕时音频引擎才启动

> iOS 的静音拨片会同时静音网页音频（系统行为）；真机要出声请关掉静音开关。

### 素材署名

- 音乐：**Retro Synthwave Loops** by Tomasz Kucza（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）
- 音效：**Chiptune SFX Pack**（CC0）
- 画面：全部程序化绘制，无图片素材

## 存档

三个独立存档槽，存在浏览器本地（localStorage），不需要账号。

| 时机 | 行为 |
|---|---|
| **每晚结算后天亮** | 自动保存到当前槽（出一条提示） |
| **右上「菜单」→ 保存进度** | 手动保存（夜间不可用） |
| **右上「菜单」→ 读取存档** | 三个槽任选载入（会覆盖当前进度） |
| **右上「菜单」→ 回到主菜单** | 先存一次再回开场页，可以换槽 |

存档包含：天数、金钱、金库、威望、家等级、全部建筑与等级、保安、NPC 入队、街史进度、剧情选择、电力分配、当前时刻。

夜间保存会自动回滚到**当天白天开头**，避免读档卡在半夜却没有敌人。

右上角的 **「菜单」** 按钮随时打开（游戏会暂停）：

| 项 | 作用 |

| 布防 · 调度 | 每个保安守左 / 守右 / 自动 |
| 回到主菜单 | 自动保存后回开场页，可换档重开 |

## 时间

| 阶段 | 时长 | 倍速 |
|---|---|---|
| 白天 | 200 秒 | 1× / 2× / 4× |
| 黄昏 | 45 秒 | 1× / 2× / 4× / 跳过 |
| 夜晚 | 150 秒 | 1× / 2× / 4× |

夜晚也可以加速（v0.3 起）：节奏交给你自己，2×/4× 会同时加快敌人、炮塔、保安与波次间隔。

### 夜袭节奏

一晚分若干波，**第 1 波从右、第 2 波从左，交替来**（不是只从一侧）。第 1 天 2 波 × 2 名，往后每 2 天多一波、每 3 天每波多一人。

> 黄昏的布防面板会列出**整晚每一波的方向和人数**（后续波次只报方向与人数，阵容进场才知道），所以可以提前把保安分到两边。

路障（挡路）· 地刺（踩踏伤害）· 摄像头（炮塔射程 +40%，带扫描光锥）· 电击门（接触伤害 + 眩晕，有电弧特效）· 炮塔（主力输出）

| 敌人 | 血量 | 每次伤害 | 出现 |
|---|---|---|---|
| 小偷 | 20 | 4 | 第 1 天 |
| 砸店党 | 40 | 8 | 第 4 天 |
| 飞车党 | 30 | 6 | 第 8 天 |
| 黑帮 | 80 | 10 | 第 15 天 |
| 内鬼 | 35 | 7 | 第 22 天 |
| 赛博改造人 | 200 | 16 | 第 30 天 |
| 清街队队长 | 150 | 20 | 第 35 天 |

血量每天 +3%（按当天重算）。第一晚只有 2 波 × 2 只小偷，一名近战保安（120 血、8 伤/0.6 秒）足够守住。

**战斗规则**：敌人贴到保安就**停下互殴**，不再绕过去砸店；保安近战射程 13。敌人头顶**常显血条**（绿 >55%，黄 >28%，红），命中会飘伤害数字。

### 战斗人员

近战保安 / 远程保安 / 战斗机器人 / 店员（每个 +35% 收入，占一个窗口）

- 会**自动巡逻**（白天在自己的半条街上来回走），夜间按布防设置守左 / 守右 / 自动
- 互不碰撞：同侧多人自动左右错开站位
- 活动范围限制在**街道最外侧建筑之间**，不会跑出街
- **远程自动站在近战与机器人身后**
- 每日自动回复 35% 血量；药房提升血量上限

### 八位特殊 NPC

每位都有独立造型、门槛、任务与入队能力：

- **老周**（建造）第 4 天 · 建 3 座防御 → 拆建免费
- **阿豹**（战斗）累计击杀 30 → 近战伤害 +50%
- **老陈**（战斗）第 8 天 · 击杀 60 → 全体伤害 +25%
- **梅姐**（金融）当铺 Lv2 · 还清贷款+存款 3 万 → 金库利息 ×2（只加成 3 万以内的部分）
- **阿霓**（防御）有网吧+营业额 8000 → 炮塔射程 +30%
- **小雨**（经营）药房 Lv2 · 撑过 4 天 → 全街自动补货
- **小满**（经营）小饭馆 Lv2 · 单日 5000 → 客流 +50%，夜间多 1 波
- **零号**（真相）家 Lv6 + 5 人入队 · 守 40 天 → 真结局路径

### 陈晓（第四幕 NPC）

第四幕解锁后会站在街口（家右侧），走过去按 **E** 可以签字或拒绝。**只写进剧情档案，不改任何经营数值**（拒绝会 +20 威望）。

### 其他系统

- 昼夜循环 + 倍速 + 黄昏跳过 + 跨夜自动归 1×
- 随身现金 / 小金库（分段计息 2.0%→4.0%/天，存得越多利率越高）/ 当铺贷款（日息 5%，逾期掉威望）
- 电力：每日重置、超载断电、手动优先级
- 家被破坏 → 降 1 级 / 金库 -40% / 当晚结束 / 次日 260 秒
- 掉落物 → 当铺变现
- 黄昏布防：每人可设「守左 / 自动 / 守右」，自动会跟着敌人方向
- 面板支持点击外部关闭（结算与结束面板除外）

## 街史（剧情）

剧情是**补充项**，不弹窗、不锁操作、不影响胜负。全部内容在右上 **「街史」** 里：

| 幕 | 解锁条件 |
|---|---|
| 第一幕 · 这条街不对劲 | 老周入队 |
| 第二幕 · 钱从哪来 | 阿豹 + 梅姐入队 |
| 第三幕 · 零号是谁 | 阿霓 + 小雨 + 老陈入队 |
| 第四幕 · 代价 | 小满入队 + 家 Lv5（陈晓出现在街上） |
| 第五幕 · 第七个雨夜 | 零号入队 |

解锁时屏幕上会出一条**不打断操作的提示条**，结算面板底部也有一行随进度变化的短句。

**结局档案**

| 结局 | 怎么来 |
|---|---|
| A · 熄灯 | 老周 + 阿霓 + 零号在队后，家右侧出现**中枢门**，玩家自己走过去按 E 才会发生（可以一辈子不按） |
| B · 体面离场 | 在陈晓那里签字 |
| C · 第七个雨夜 | 八人全部入队 + 守过 50 天 + 没签字 |
| D · 清街 | 威望归零 |

世界观：清河街要被「城市更新」。三十年前地下埋过「零号工程」——一套夜间自动保护街区的中枢。项目失败，中枢封存。零号是它唯一留下的人形接口，还在执行那条没被取消的指令。

## 美术

全部像素图形由代码程序化绘制，**零图片素材**，内部渲染 320×180 后整数放大。

### 人物

统一的人形管线：**分部件描边 → 腿 → 靴 → 躯干 → 手臂 → 手 → 颈 → 头 → 脸**。

- 描边不再是统一黑边，而是每个部件自身的暗色（外套描边取自外套色），贴合成像**手绘像素**而不是贴纸
- 三段明暗：受光边、基色、背光侧 + 2×2 棋盘抖动过渡
- 头部 8 行：眉、眼（含 1px 眼神光）、鼻影、嘴、下颌收窄、下巴阴影、耳朵、颧骨高光
- 服装细节：翻领 V 字、拉链与拉头、两个口袋、腰带扣、下摆褶皱、袖口、肩甲、手掌与拇指
- 靴子区分靴筒 / 鞋头高光 / 鞋底 / 鞋跟，不再是"两根柱子"
- 接地阴影三层软过渡；霓虹轮廓光打在头与肩（双色：霓虹 + 暖白）

### 建筑

- 墙面材质：竖向面板接缝（暗缝 + 亮边）、雨痕、右侧 2×2 抖动体积阴影、墙根积垢渐变
- 二层窗：窗套（外框 / 过梁 / 窗台）、十字窗棂、部分卷帘、员工窗口空位有暗窗提示
- 店面：玻璃窗棂、室内冰柜与收银台剪影、玻璃斜向反光、门框与台阶
- 屋顶：女儿墙压顶、灯箱、天线、空调外机（含支架与滴水管）、墙面配电箱与走线
- 霓虹对墙面有环境光溢出（招牌 / 雨棚 / 窗光三种颜色分别叠加）

### 场景

- 人行道：交错铺砖（每块砖带上沿受光与下沿阴影）、裂缝、污渍、积水反光、路缘石高光
- 街边小物：消防栓、垃圾袋、护柱、排水格栅、井盖
- 地下剖面：沥青层 → 碎石垫层 → 土壤颗粒，主电缆槽（三条发光缆芯 + 卡箍）、主排水管（支架与滴水）、落水管、接线盒（三色指示灯）、路面漏光
- 天空：云带、日冕、月相、星星、空中广告飞艇（带航行灯）、城市光污染雾
- 远景：天际线顶部边缘光、右侧体积阴影、底部压暗，形成空气透视
- 后期：霓虹泛光（bloom）、湿地反光、扫描线、暗角

## 本地运行

用浏览器打开 `index.html` 就能玩，无需构建。

但**音频是外部文件**（`audio/`），`file://` 协议下浏览器会拦截本地文件请求：音乐不会播放、音效会回退到合成音。
想在本机听到完整音频，用任意静态服务器：

```bash
python -m http.server 8123
# 打开 http://127.0.0.1:8123/
```

线上链接不受影响。

调试参数（跳过开场与存档）：

- `?demo` — 直接进入已开工的街景
- `?demo&night` — 夜晚战斗场景
- `?demo&menu` — 打开建造菜单
